# 🎱 AhaduPool

> **Built By Students. Powered By Passion.**

AhaduPool is an ambitious multiplayer 8-ball pool game built from scratch by a team of enthusiastic Ethiopian software engineering students. With zero initial funding, we've poured countless late-night coding sessions into creating a realistic, competitive, and highly scalable game. 

![Status](https://img.shields.io/badge/Status-In%20Development-orange)
![Version](https://img.shields.io/badge/Version-1.0.0-blue)

---

## ✨ Features

- **🌐 Real-time Multiplayer:** Play seamlessly with friends in real-time.
- **🤖 AI Opponents:** Practice and hone your skills against smart bot opponents.
- **🏆 ELO Ranking:** Climb the competitive ladder and prove you're the best.
- **📱 Cross-platform:** Designed to run beautifully across multiple devices.
- **📊 Live Match Stats:** Track your performance, win rate, and accuracy in real-time.
